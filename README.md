# MealsOnTheGO

**MealsOnTheGO** is a cross-platform mobile food delivery app built using **React Native**. This project demonstrates strong practices in reusable component design, performance optimization, and user-centric feature development.

## 🚀 Features

- 📱 Intuitive and responsive UI for both iOS and Android.
- 🍽️ Browse food categories and meal details.
- ❤️ Mark meals as favorites.
- 🛒 Add meals to your favorites list and manage them easily.
- 🔍 Filter meals based on dietary preferences like gluten-free, vegan, and more.
- 🧭 Seamless navigation using React Navigation.

## 🛠️ Technologies Used

- **React Native** – Build native apps using JavaScript and React.
- **JavaScript (ES6+)** – Core programming language.
- **React Navigation** – Navigation and routing.
- **Redux (optional if implemented)** – State management.
- **Custom Components** – Built for modularity and reusability.

## 🚀 Getting Started

### Prerequisites

- Node.js
- React Native CLI
- Android Studio / Xcode (for emulator/simulator)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Triankit/mealsOnTheGO.git
   cd mealsOnTheGO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start Metro Bundler:
   ```bash
   npx react-native start
   ```

4. Run the app:

   - For Android:
     ```bash
     npx react-native run-android
     ```

   - For iOS:
     ```bash
     npx react-native run-ios
     ```
